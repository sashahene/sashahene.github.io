Project Overview

An ongoing embedded systems project integrating custom TouchDesigner animations with an ESP32-S3 circular LCD. Developing motion-responsive character behavior and a custom web-based platform for animation management, hardware communication, and interactive control.

Technologies: ESP32-S3, C++, Arduino IDE, TouchDesigner, I²C, QMI8658
